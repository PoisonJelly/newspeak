# 셀프테스트 기록

- 스크립트 단위 테스트: `python scripts/selftest.py`
- 스킬 전체 셀프테스트: 입력 글 → 스킬 적용(독립 에이전트) → lint·gate + 독립 검토 → 예외나 AI 말투가 나오면 스킬 수정 → 반복

| 5 | 영어 건강 요약 | rewrite | 없음 | major 1, minor 5 | 'sheds light on … one simple habit:' 잔존, 'promising tool', 부정확한 괄호 풀이, 출처 없는 문장 통째 삭제, 3개 나열 항목 삭제, 'should' 중복 |

반영한 수정
- lint: KO-D15(결론 소제목), KO-D16(추세 도입문), KO-H2(문두 인과 접속사), EN-A6(보도자료 상투구), EN-D3(결론·평가 소제목) 추가. KO-C11에 '-면' 추가(명사·'반면' 제외). KO-L2에 해요체 '알아볼게요' 추가. EN-A1·A3·G1 표현 보강. 이모지 범위(⏰ 등) 보강. 줄 번호 밀림 수정. KO-E2 해요체 끝 세 음절 기준. 등급 상승 표시 `↑`. EN-B1 단어 전부 표시.
- gate: 변경률을 rewrite/delete로 분리. 서법 검사를 문장 정렬 방식으로 바꿈(지운 문장 표지는 NOTE). '중요하다'·명령형을 당위 표지에 포함. `--allow 키 --reason` 추가. `--mode write`(지시서 대조) 추가. 'unchanged' NOTE.
- 문서: SKILL.md 4-1절 판단 규칙 14개, write 모드 절차·장르 허용 범위·해요체 종결 변주, 패턴 문서 갱신.
- 단위 테스트 22개 → 32개, 전부 통과.

- 문서: SKILL.md 4-1절 15~26번(정보 담긴 대조 보존, 구체 감각 대조 예외, 대조군 규칙, SNS 공식·이모지·마크다운, 격언 목록, 반복 재안내, 번역투 몰림, 경구 항목, 처방 충돌, 맺음 문단 선택, 변경 목록), 심각도 표기를 lint와 일치(KO-D6·D10·I5).

실행자가 보고한 규칙 충돌
- 4-1절 18번이 댓글 유도 문장을 "평범한 질문 하나"로 바꾸라고 해서 gate 경고와 부딪혔다. 검토 결과 gate가 옳았다(요청 동사 소실).
- '#' 삭제 규칙이 해시태그까지 지우라는 뜻으로 읽혔다. SNS 이모지 허용 개수가 18번(1개)·KO-C5(몇 개)·lint 안내(a few)에서 서로 달랐다.
- 허용된 이모지 1개와 구독 요청 1줄이 S2로 세어져 등급을 깎았다.
- 추측의 must('how frustrating it must be')를 당위로 세어 deleted-ought 경고가 났다. 챗봇 머리말·꼬리말 삭제가 delete 비율에 들어갔다.
- 문서의 삭제 경고 기준(35%)과 코드(40%)가 달랐다. EN-D2가 S3→S2로 올라가도 `↑`가 없었다.
- KO-I4 처방(당위 문장 앞으로 옮기기)이 코드 블록을 이끄는 기술 문서 지시문과 부딪혔다. '첫 문단 하나는 둔다'가 두 뜻으로 읽혔다. S3가 의무인지 허용인지 모호했다.
- 영어 커버레터 규칙, 메일 장르 규칙(진짜 요청 vs 'Let me know if'), write 모드에서 자조 반응·용어 풀이를 써도 되는지, 블로그 도입부의 본문 안내 한 줄이 메타 발언인지 기준이 없었다.

반영한 수정
- lint 추가: KO-A1b('~에 대해 설명합니다'), KO-G5('~라고 할 수 있어요' 얼버무림), EN-H7(고객 응대 상투구), EN-M3(커버레터 상투구), EN-M4(정형 자조), EN-L3(문단 첫 문장 길이 균일).
- lint 보강: KO-A8 이중 피동 '읽혀지다·잊혀지다·닫혀지다' 등('밝혀지다·알려지다' 제외), KO-L2 '~에 대해 알아봤어요', KO-K8 기준(1회 S3, 2회+ S2)과 안내문(요청 동사는 남김), KO-G3 안내문(화제 전환 '다만,'), EN-C1 축약 없는 'are not just X; they are Y', EN-A1 'the transformative role that X play', EN-A4 복수형('vibrant hubs'), EN-B1 활용형을 한 단어로 셈(fostered, seamlessly 등), EN-D2 승격 표시 `↑`, KO-I4 코드 블록·표를 이끄는 지시문 제외.
- lint·gate `--genre sns|chat`: SNS·설명란은 머리글 이모지와 요청 줄을 장르 관례로 셈. 메신저는 이모지 1~2개 허용.
- gate: 추측의 must 제외, 챗봇 틀(머리말·꼬리말·구분선)을 변경률에서 빼고 NOTE로 알림, 기여도 격상 경고(contribution, 'role in X-ing' → 'I X-ed').
- 문서: SKILL.md 0단계 `--genre`, `↑` 뜻, 삭제 기준 40%, 챗봇 틀 NOTE, mood·deleted-ought 처리 사례(요청 동사는 되살림, 가벼운 권유는 지움, 할 일은 남김), contribution 키, 4-1절 6번(맺음 나열 항목 대조), 18번 재작성(요청 동사 유지, 머리글 이모지, 해시태그 보존), 38~44번(기여 정도, 영어 커버레터, 고유 주장 문단 압축, 목록 변환, 메일, 문단 첫머리 '다만,', '~에 대해 설명합니다'), S3 정의(고칠 수 있음, 의무 아님), write 모드(톤 반응·용어 풀이 허용 범위, 글머리표→문단 짝짓기 금지, 본문 안내 한 줄), 영어 규칙(사람 주어, 정형 자조 1개, 짧은 글 문장부호). 패턴 문서 갱신.
- 단위 테스트 36개 전부 통과. 대조군 2개 0건 유지. 1~20회 결과물 재검사에서 새 오탐 없음(15회의 EN-C1은 직접 인용이라 gate가 뺌).
